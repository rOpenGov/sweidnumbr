# pin_coordn_correct

Remove the change of day in coordination numbers (to enable age
calculation).

## Usage

``` r
pin_coordn_correct(pin)
```

## Arguments

- pin:

  Vector of pins at format atandard fromat 'YYYYMMDDNNNC'. See
  [as.pin](https://ropengov.github.io/sweidnumbr/reference/as.pin.md).

## Value

Character vector with pin, corrected for coordination numbers.
