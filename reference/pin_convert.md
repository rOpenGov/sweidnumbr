# pin_convert

Converts one pin to standard format

## Usage

``` r
pin_convert(pin, format)
```

## Arguments

- pin:

  A character element of length one.

- format:

  Which format should be converted. See
  [as.pin](https://ropengov.github.io/sweidnumbr/reference/as.pin.md).

## Value

Character element on standard format.
